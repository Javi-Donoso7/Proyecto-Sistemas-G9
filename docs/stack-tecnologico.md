# Definición del Stack Tecnológico

Para el desarrollo de la aplicación Jugada Maestra se seleccionó un stack simple, funcional y compatible con desarrollo asistido por IA.

- Frontend: React + Vite.
- Backend: Node.js + Express.
- Base de datos: SQLite.

React permite construir interfaces dinámicas y responsivas basadas en el prototipo generado en Stitch. Node.js con Express permite crear una API REST liviana para conectar la interfaz con la base de datos. SQLite permite implementar una base de datos SQL relacional sin configurar un servidor externo, suficiente para el alcance académico del proyecto.
